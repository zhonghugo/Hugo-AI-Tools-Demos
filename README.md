# AI 小工具 Demo 合集

每天从全球 AI 工具资讯里挑一条最有价值的，做成一个**可直接运行的小工具 Demo**。所有 Demo 都是单文件 HTML，浏览器打开即用，可下载、可转发，无需安装任何环境。

方向聚焦：**流程自动化 / RPA+AI 落地 / 数字化运营**。

## 这里有什么

| 内容 | 位置 | 说明 |
|---|---|---|
| 每日资讯快照 | `daily_news_0913.json` ~ `daily_news_1110.json` | 8:30 自动采集（缺 9/22；当日无合适资讯的日期仅有快照无 demo，如 10/30） |
