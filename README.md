# AI 小工具 Demo 合集

每天从全球 AI 工具资讯里挑一条最有价值的，做成一个**可直接运行的小工具 Demo**。所有 Demo 都是单文件 HTML，浏览器打开即用，可下载、可转发，无需安装任何环境。

方向聚焦：**流程自动化 / RPA+AI 落地 / 数字化运营**。

## 这里有什么

| 内容 | 位置 | 说明 |
|---|---|---|
| 每日资讯快照 | `daily_news_0913.json` ~ `daily_news_1016.json` | 8:30 自动采集（缺 9/22） |
| 小工具 Demo 作品集 | `demos/作品集总览/AI小工具Demo作品集_总览.html` | 全部 37 个 Demo 的展示入口，点开即用 |
| Demo 台账 | `demos/作品集总览/AI小工具Demo台账.xlsx` | 日期/工具名/来源/星级/链接/状态一表汇总 |
| 每个 Demo 源文件 | `demos/2026-09-XX_工具名/` | 含单文件 HTML 与说明 |

## 使用方式

1. 打开 `demos/作品集总览/AI小工具Demo作品集_总览.html` 查看全部作品
2. 任意 Demo 卡片点开即用——单文件 HTML，可下载、可转发
3. 想深挖某个工具，去 `demos/对应日期_工具名/` 看源文件与说明
