# 求职画像模板

画像用于参数化岗位搜索与筛选，是 skill 的唯一必填输入。每次调用先按本模板解析；用户未提供完整画像时，按字段逐项引导填写。

## 字段说明

| 字段 | 必填 | 说明 |
|---|---|---|
| name | 否 | 称呼，用于推送摘要 |
| city | 是 | 目标工作城市 |
| directions | 是 | 求职方向列表，主攻在前 |
| industry_preference | 否 | 行业偏好（如 餐饮/连锁/本地生活），命中则优先级更高 |
| experience | 否 | 经验背景一句话，用于写「匹配理由」 |
| highlights | 否 | 核心成果列表，用于写「匹配理由」 |
| salary_target | 否 | 期望薪资（如 3万/月） |
| salary_floor | 否 | 薪资底线，明显低于底线不收录 |
| level_preference | 否 | 层级偏好（经理/主管/资深专家） |
| exclusions | 否 | 排除项：不收录的岗位类型/平台/地点，逐条写明 |
| daily_target | 否 | 每日收录条数目标（默认 10-20） |

## JSON 填写模板

```json
{
  "name": "",
  "city": "深圳",
  "directions": ["方向A（主攻）", "方向B（备选）"],
  "industry_preference": "",
  "experience": "",
  "highlights": ["成果1", "成果2"],
  "salary_target": "",
  "salary_floor": "",
  "level_preference": "",
  "exclusions": [],
  "daily_target": 15
}
```

## 使用要点

- 「匹配理由」字段 = 画像的 highlights + directions 与岗位职责的交叉点，写 1-2 句具体的话，不要空泛
- 排除项是硬约束，命中即不收录；方向/薪资/地点是软约束，按优先级取舍
- 同一画像可复用于定时任务与手动调用；画像变化（如调整底线）时更新 JSON 并同步定时任务 query
- 每日收录结构建议：AI运营/AI变革/AI转型占比最高 → 数字化运营/数据运营其次 → RPA/流程自动化实施少量 → 纯流程管理岗 0 条
