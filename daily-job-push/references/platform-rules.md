# 平台与链接规则

本文件是搜索与收录环节的硬性规范，来自多轮实战踩坑，每次调用必须遵守。

## 允许的搜索渠道

- BOSS直聘（site:zhipin.com）
- 猎聘（site:liepin.com）
- 智联招聘（site:zhaopin.com）
- 前程无忧（site:51job.com）
- 脉脉（site:maimai.cn）
- 公司官网 / 官方招聘页

## 禁用平台

| 平台 | 原因 |
|---|---|
| 拉勾网 | 已关停，严禁使用 |
| 鱼泡直聘 | 低质量/来源不可靠，岗位一律不收录 |
| 其他非主流低质聚合站 | 不收录 |

## 明细页 URL 规则（收录硬性要求）

链接必须直达岗位明细页，**严禁使用搜索页/列表页/公司页**：

| 平台 | 合格明细页特征 | 不合格（严禁收录） |
|---|---|---|
| 猎聘 | 含 `/job/<id>.shtml` 或 `/a/<id>.shtml` | `/city-sz/` 城市搜索页、`/s/` 搜索页、`/company-jobs/` 公司岗位列表页 |
| BOSS直聘 | 含 `job_detail`：`https://m.zhipin.com/job_detail/<id>.html` 或 `https://www.zhipin.com/job_detail/<id>.html` | `zhaopin/` 搜索页、`gongsi/` 公司页 |
| 脉脉 | 含 `article/detail?efid=`（Web 职位详情页，推荐形态）、`/web/job/` 或 `/web/feed/detail?fid=` 的职位详情页 | 搜索页、品牌主页、社区帖 URL |
| 智联招聘 | 岗位详情页 | 城市/搜索/公司列表页 |
| 前程无忧 | 职位详情页 | 搜索/列表页 |
| 公司官网 | 具体职位页 | 官网首页/招聘列表页 |

要点：

- **拿不到明细页链接的岗位不收录**（宁可少收，不收废链接）
- 搜索结果给出搜索页时：抓取页面提取岗位卡片中的明细页链接（猎聘列表页可用手机 UA 的 curl 抓取后正则提取 `/job/` 或 `/a/` 链接）
- 历史教训：猎聘列表页链接点开后是搜索页而非明细页，收录前必须确认链接形态

## 岗位有效性检查（收录前必做）

1. 摘要/页面出现“职位已关闭”“已下架”“停止招聘”“已停招”“已下线”“已失效”等提示 → 一律不收录
2. BOSS直聘详情页顶部“职位已关闭”、猎聘“已下架/失效”、脉脉“已下线/停招” → 不收录
3. 拿不准的链接 → 先抓取页面验证是否仍在招聘，已失效的排除

## 历史踩坑记录

- 猎聘大量列表页链接点开后跳转搜索页 → 已批量替换为明细页，后续收录必须检查
- 无明细页链接的岗位（如华秋智联）→ 不收录
- 薪资明显偏离画像（如 AI 智能体岗 100-200k，画像 2.5-3.5万）→ 不收录
- 脉脉搜索常只返回品牌主页/社区帖 → 仅收录含 `article/detail?efid=`、`/web/job/` 或 feed 详情的岗位，搜不到明细页就如实说明该渠道无新增
- **脉脉 Web 职位详情页形态**：调研自公开开源项目（maimai-cli / Super_Employee 等），脉脉职位详情页为 `maimai.cn/article/detail?efid=<加密串>&fid=<数字>`，公开可访问含 JD 全文；从 App API 拿到的 `ejid` 可拼出详情页；该形态收录前需抓取验证仍可访问
- **脉脉 API 可选通道**：配置过 access_token 时可走 `search_front/app/job_search` 端点直接拿岗位列表（见 references/maimai-api.md），否则回退 general_search 常规搜索
- **脉脉通道实测（2026-10-05）**：`article/detail?efid=` 明细页经 general_search 可稳定检索、web_fetch 无需登录即可读取 JD 全文，收录链路已验证可行；但**RPA/流程自动化等主方向关键词在脉脉公开索引中多为科普/行业分析文章，真实招聘帖命中少**，而 **AI 运营/AI 相关岗位招聘帖命中率高** → 脉脉搜索优先用 AI 运营类关键词，主方向岗位转品牌页（`brand/home/`）或 API 通道补充
- **脉脉招聘帖特性**：岗位多为 HR 个人发布（如"简历直达业务"帖），无统一岗位页；发布数月后可能已关闭，收录前逐条验证有效性
- **猎聘城市页动态渲染**：猎聘城市搜索页（`/city-*/`）HTML 常静默不渲染岗位（curl 返回约 4.9KB 空壳页），需改用公司页/搜索页 HTML 提取 job id 后逐条 curl 明细页验证
- **大厂城市页静默**：华为等城市页 PC/iPhone UA 均可能不命中，需用 web_fetch 定位岗位信息
- **BOSS/脉脉 curl 反爬**：BOSS 返回"请稍候"页、脉脉需登录，不要用 curl 验证 BOSS/脉脉，用 general_search 定位 job_detail 链接 + 状态判断
- **北森 zhiye 官网系统（喜茶等）**：`heytea.zhiye.com/jobs` 列表页可读到完整 JD，但岗位详情页 JS 渲染、`/api/job/list` 500、`/portal/detail/0` 空壳 → 拿不到独立明细页 URL 的官网岗不收录
- **硬性门槛岗**：985/211/硕士硬性学历、专职数据产品/大数据产品经验、算法框架硬性要求（TensorFlow/PyTorch/深度学习）→ 不收录（用户业务+落地型背景）
- **更新超 90 天的岗位**：谨慎收录（可能已招满）；以生态合作/BD 资源为核心的 AI 岗（如"向 ISV/SI 推广合作"）→ 不收录
- **薪资偏低的工程师职级岗**：中位月薪低于 2.5 万底线且职级非经理级（如 15-25k×15薪"工程师"）→ 不收录
