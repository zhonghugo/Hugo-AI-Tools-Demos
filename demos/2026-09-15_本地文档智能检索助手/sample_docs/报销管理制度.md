# 公司报销管理制度

## 一、总则

为规范公司费用报销流程，加强成本控制，提高财务工作效率，特制定本制度。本制度适用于公司全体员工。

## 二、报销范围

1. 差旅费：包括交通费、住宿费、餐饮补助费
2. 业务招待费：客户来访、商务洽谈等产生的合理费用
3. 办公费：办公用品、打印费、快递费等
4. 培训费：经批准的外部培训、会议费用
5. 其他费用：经部门负责人和财务部门确认的合理支出

## 三、报销标准

### 3.1 差旅费标准

- 交通费：高铁二等座、飞机经济舱，特殊情况需提前审批
- 住宿费：一线城市不超过500元/晚，二线城市不超过400元/晚
- 餐饮补助：100元/天，凭票报销或按标准发放

### 3.2 业务招待费标准

- 单次招待费用不超过2000元，需提前报备
- 超过2000元需部门总监审批
- 招待对象、人数、事由需在报销单中详细说明

## 四、报销流程

1. 员工填写报销单，粘贴原始发票
2. 部门负责人审核签字（确认费用真实性和合理性）
3. 财务部门审核（票据合规性、标准符合性）
4. 财务总监审批（超过5000元需总经理审批）
5. 出纳付款（每月15日和30日集中付款）

## 五、注意事项

1. 发票必须为正规增值税发票，抬头为公司全称
2. 报销时限：费用发生后30天内提交，逾期不予报销
3. 严禁虚报、冒报，一经发现严肃处理
4. 电子发票需打印后附在报销单后，并提供PDF电子版

## 六、附则

本制度自发布之日起执行，由财务部门负责解释和修订。
