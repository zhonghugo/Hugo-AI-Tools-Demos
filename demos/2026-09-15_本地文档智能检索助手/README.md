# 本地文档智能检索助手

## 解决什么问题

企业文档分散（制度/流程/产品手册/历史项目），找信息靠手动翻文档，AI代理每次都要重新读取文档上下文，浪费Token且容易遗漏。

本工具自动扫描文档文件夹，建立倒排索引，通过Web界面提问，快速返回相关段落（关键词高亮）。

## 快速开始

```bash
# 1. 进入目录
cd 本地文档智能检索助手

# 2. 运行（sample_docs/ 已包含4个示例文档）
python3 doc_search.py

# 3. 浏览器打开
# http://localhost:8888
```

## 功能特点

- **零依赖**：仅使用Python标准库，无需安装任何第三方包
- **本地运行**：数据不出本地，保护企业敏感信息
- **TF-IDF算法**：词频×逆文档频率，智能排序相关段落
- **中英文分词**：支持英文单词、中文单字和双字词
- **关键词高亮**：搜索结果中匹配词自动高亮显示
- **Web界面**：简洁美观的搜索界面，支持回车搜索

## 如何使用自己的文档

1. 将文档（`.txt` / `.md` / `.csv`）放入 `sample_docs/` 文件夹
2. 重新运行 `python3 doc_search.py`
3. 工具会自动扫描并索引新文档
4. 支持子文件夹，会递归扫描所有文档

## 搜索技巧

- 输入具体问题：如"报销流程是什么？"、"库存预警阈值是多少？"
- 输入关键词：如"年假"、"安全库存"、"定价方法"
- 中英文混合搜索都支持
- 搜索结果按相关度排序，最相关的段落排在最前

## 配置说明

在 `doc_search.py` 顶部的 `CONFIG` 字典中可修改：

```python
CONFIG = {
    "docs_dir": "sample_docs",        # 文档文件夹路径
    "host": "0.0.0.0",                 # Web服务器地址
    "port": 8888,                       # Web服务器端口
    "supported_extensions": [".txt", ".md", ".csv"],  # 支持的文档格式
    "max_results": 10,                  # 最多返回结果数
}
```

## 技术原理

1. **文档扫描**：递归扫描文档文件夹，读取所有支持格式的文本文件
2. **分词处理**：英文按空格分词，中文按单字+双字词（bigram）分词
3. **倒排索引**：建立"关键词 → 文档段落"的映射，记录词频(TF)
4. **TF-IDF评分**：搜索时计算查询词在每个段落的TF-IDF得分，按得分排序
5. **上下文提取**：返回匹配段落及其前后段落，提供完整上下文
6. **关键词高亮**：在前端将匹配的查询词高亮显示
