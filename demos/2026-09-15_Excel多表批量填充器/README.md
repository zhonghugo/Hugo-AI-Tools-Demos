# Excel多表批量填充器（Demo）

> 源自「AI工具资讯日报」2026-09-13 头条：**国企原始人真心求教：Excel多表数据自动化怎么搞**
> （推荐指数 5星，赞1309 / 藏1412 / 评80）
>
> 痛点：国企成本控制专员，每天要从合同/清单里扒数据填进 5 套不同版本的 Excel（对内/对外/合规），
> AI 总搞混字段和公式，手动检查修正耗时。

## 这个工具解决什么问题

把「每天重复的填表工作」变成**一次配置、永远复用**：

- 你只需在 `config.json` 里写清楚：源表哪一列 → 目标表哪个单元格/列
- 工具自动读取源 Excel → 按映射批量填充多套目标表
- **保留目标表原有公式**（含税金额=金额×1.13、合计=SUM、序号=ROW() 等）和原有格式
- 换新项目、新公司：**只改 config.json，不改代码**

## 快速开始

```bash
# 1. 生成示例数据（只需一次）
python3 generate_sample_data.py

# 2. 先预演，看看会填什么（不写文件）
python3 batch_filler.py --dry-run

# 3. 正式执行批量填充
python3 batch_filler.py

# 4. 打开 sample_data/ 下的目标表查看效果
```

依赖：`openpyxl`（`pip install openpyxl`）。

## 示例场景

生成的数据模拟「8 份合同 → 4 套表」：

| 目标表 | 填充内容 | 演示点 |
|---|---|---|
| 对内台账.xlsx | 合同编号/项目/供应商/金额/日期/负责人 | 含税金额公式 =D×1.13 自动联动，合计行 SUM 自动汇总 |
| 对外报表.xlsx | 合同编号/项目/金额/日期/备注 | 序号列用 ROW() 公式自动编号 |
| 合规检查表.xlsx | 合同编号/项目/供应商/金额/付款方式/负责人 | 检查结论列默认「待查」不被覆盖 |
| 付款计划表.xlsx | 合同编号/项目/供应商/金额/付款方式 | **列值转换**：付款方式文字→首付款比例数值，首付款金额公式 =D×E 联动 |

## 配置文件怎么用（新项目）

```jsonc
{
  "源表": "你的源文件.xlsx",          // 数据来源
  "源表Sheet": "合同明细",            // 源表工作表名
  "目标表": [
    {
      "文件": "目标文件.xlsx",         // 目标表路径
      "Sheet": "台账",                // 目标工作表名
      "起始行": 2,                    // 从第几行开始填（第1行通常是表头）
      "列映射": [                      // ★ 核心：源列 → 目标列
        { "源列": "合同编号", "目标列": "A" },
        { "源列": "合同金额", "目标列": "D" }
      ],
      "固定单元格": { "I1": "填表人：张会计", "I2": "填表日期：{{今天}}" },
      "列值转换": {                    // 可选：文字转数值等
        "E": { "分三期": "0.40", "预付30%": "0.30" }
      }
    }
  ]
}
```

要点：
- **源列名**要和源表表头一致；**目标列**用字母（A/B/C…）
- 目标表里已有的**公式不会被覆盖**，只写映射到的单元格
- 源值为空时**跳过**，不破坏目标表模板里的默认内容（如「待查」）
- 固定单元格支持 `{{今天}}` 自动替换为当天日期
