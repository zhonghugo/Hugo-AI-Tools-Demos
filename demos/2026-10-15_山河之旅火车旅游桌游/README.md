# 山河之旅 (Discover China) 线上版 — 项目说明

中国地图火车旅行桌游《山河之旅》的线上版项目基座与理解文档。

## 目录内容

| 文件 | 说明 |
| --- | --- |
| `山河之旅_代码基座理解报告.html` | 代码基座理解报告：7 段模块架构、核心机制要点、回合状态机、下一步迭代挂钩点勘察（多人联机 / 合成音效） |
| `discover_china_3d.html` | （待上传原文件）游戏本体：基于 Three.js 的单文件可运行版本 |

## 基座概览

- **形态**：单文件零构建依赖（2885 行），Three.js r128 + 手写球面阻尼相机（无外部 OrbitControls）
- **拓扑**：50 城 / 83 边中国铁路网，5 色车票 + GO 万能票，双六面骰
- **渲染**：4096×4096 离屏 Canvas 绘本底图（34 省真实省界、台湾/海南本岛、南海诸岛十段线附图框、定制矢量地标）
- **寻路**：受限深度无环全路径枚举 + 多路线选择弹窗；逐城分步跳跃动画（440ms/跳）
- **玩法**：所有玩家从北京出发，投骰得票 → 沿铁路逐城移动，途经公共目标得分 → 先攒满 10 分并返回秘密城市者获胜

## 运行方式

直接用浏览器打开 `discover_china_3d.html`（file:// 可运行）。运行时需联网加载 Three.js（cdnjs + 字节 CDN 双容灾）与阿里云 DataV 省界 GeoJSON（失败自动回退手绘省界）。
