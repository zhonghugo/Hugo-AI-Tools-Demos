# 企业AI落地诊断助手

## 这个工具解决什么问题

中小企业老板知道AI很重要、想用，但面对上百个AI工具和各种说法，不知道自己的业务哪个环节先用AI、用什么工具、怎么开始——咨询顾问太贵，自己又不知道从哪下手。

这个工具通过问卷式诊断，根据你的**行业、规模、最耗时的工作**，自动推荐：
1. 最该先自动化的3个场景（按优先级排序）
2. 每个场景的推荐方案（自建 or SaaS，附成本估算）
3. 预计每周可节省多少小时
4. 可执行的90天落地计划

## 怎么运行

**双击 `index.html` 用浏览器打开即可**，无需安装任何东西，无需联网。

支持 Chrome / Edge / Safari 任意现代浏览器。

## 怎么配置

无需配置。内置了5个行业（餐饮/零售/服务/制造/科技）的诊断规则库，根据你的选择自动匹配。

## 扩展方向

- 接入真实AI API（OpenAI/通义千问），让诊断更个性化
- 增加更多行业模板（教育/医疗/物流）
- 导出PDF诊断报告
- 对接飞书多维表格，记录企业诊断历史
- 增加ROI计算器（按人力成本估算年节省金额）

- `index.html` — 单文件应用，包含全部HTML+CSS+JS，直接双击打开
