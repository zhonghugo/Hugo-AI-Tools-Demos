RPA流程运行时守护器

参考 Herdr「session 保活 + 三态状态标记 + 阻塞通知 + agent 间编排」（45.7K stars，Rust 终端运行时）：为每个 RPA 流程配一个「守护层」——跑着跑着断了有人知道、阻塞有人介入、断点能续跑。

全部流程 Session（独立后台运行，守护层 3s 心跳）

三态口径：运行中=working 正常执行 · 阻塞=blocked 等待人工介入（验证码/MFA/异常）· 待触发=idle 等待编排调度 · 失败=failed 执行中断。

模拟 SSH 断开 / 客户端关闭 → Session 保活

Herdr 核心能力：后台 server 保持 session 存活，客户端关闭或 SSH 断开后 agent 继续工作。下面模拟断开一条会话，观察它是否仍在推进。

阻塞流程人工介入（保存上下文 → 处理 → 断点续跑）

介入点语义：流程阻塞时自动暂停并保存上下文快照（当前步骤/选择器/页面状态），人工处理后从该步骤继续，不从头重跑。

流程间编排（依赖链 + 条件分支 + 并行，参考 Herdr spawn/wait 原语）

日报导出完成后自动触发发票核验，两者都就绪后触发库存预警；供应商对账单独立并行。

执行日志回放（失败精确定位到步骤）

每条日志含操作/选择器/耗时/状态；失败步骤标红，点击「定位」在上下文中高亮。
